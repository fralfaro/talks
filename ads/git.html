¿Qué es Git?



git

  • Guarda versiones de tus archivos.
  • Permite saber qué cambió, cuándo y quién lo hizo.
  • Permite volver atrás si algo sale mal.
  • Ayuda a trabajar con otras personas sin pisarse.

Si Git o VS Code no están instalados, este es el primer paso del taller.

Instalar Git


  • Windows: descargar desde git-scm.com e instalar con opciones por defecto.
  • macOS: instalar desde git-scm.com o usar herramientas de línea de comandos de Apple.
  • Linux: instalar con el gestor de paquetes de la distribución.


git --version

Preparar VS Code



  • Instala Visual Studio Code.
  • Abre una carpeta, no archivos sueltos.
  • Usa la terminal integrada: Terminal → New Terminal.
  • Revisa el panel Source Control para ver cambios.
  • Opcional: instala la extensión GitLens.
# abrir VS Code desde terminal
code .

# si no funciona, abre la carpeta

Configurar tu identidad


Git necesita saber quién está creando los commits.


git config --global user.name "Nombre Apellido"
git config --global user.email "correo@institucion.cl"

git config --list


Usa el mismo correo que usarás en GitLab.

Crear un proyecto simple



mkdir mi-primer-proyecto
cd mi-primer-proyecto

code .
mi-primer-proyecto/
└── README.md


En VS Code, crea un archivo llamado README.md.

Iniciar Git en el proyecto



git init
git status


  • git init convierte la carpeta en repositorio.
  • git status muestra qué cambió.
  • Al principio, el archivo aparece como no versionado.

Primer commit



git add README.md
git commit -m "Agrega README inicial"

git status


  • git add selecciona cambios.
  • git commit guarda una versión.
  • El mensaje debe explicar el cambio.
  • git status confirma que todo quedó limpio.

Editar y guardar otro cambio


Agrega esto al README.md:

# Mi primer proyecto

Este repositorio es una práctica inicial de Git.

## Integrantes
- Tu nombre


git status
git add README.md
git commit -m "Actualiza descripcion del proyecto"

Ver el historial



git log

git log --oneline
a3f9c21 Actualiza descripcion del proyecto
8b2e17d Agrega README inicial


El historial cuenta la historia del proyecto.

Crear una rama



git switch -c feature/agrega-notas

# editar README.md

git add README.md
git commit -m "Agrega notas de uso"


  • Una rama separa trabajo en progreso.
  • Puedes probar ideas sin tocar la rama principal.
  • Usa nombres simples y descriptivos.

Comandos mínimos


Comando Para qué sirve
git init Iniciar repositorio
git status Ver estado
git add archivo Seleccionar cambios
git commit -m "mensaje" Guardar cambios
git log --oneline Ver historial
git switch -c nombre-rama Crear rama
git switch main Volver a rama principal

Buenas prácticas simples


  • Haz commits pequeños.
  • Escribe mensajes claros.
  • Usa git status muchas veces.
  • No guardes contraseñas ni archivos .env.
  • No trabajes todo en un único commit llamado “final”.

Actividad final


  1. Verifica que Git esté instalado.
  2. Abre VS Code.
  3. Crea la carpeta mi-primer-proyecto.
  4. Crea un README.md.
  5. Ejecuta git init.
  6. Haz dos commits.
  7. Crea una rama feature/tu-nombre.
  8. Agrega una línea nueva y haz un tercer commit.
